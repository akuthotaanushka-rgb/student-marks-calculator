# Student Marks Calculator

A beginner-friendly web project that calculates a student's total marks, percentage, grade, and pass/fail status.

## Features

- Student name and roll number fields
- Five subject mark inputs (each out of 100)
- Calculates total marks out of 500
- Calculates percentage and grade
- Pass/fail check (at least 35 marks in every subject)
- Responsive layout for mobile and desktop
- Built with HTML, CSS, and JavaScript

## How to run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter student details and marks, then select **Calculate Result**.

## Grade rules

- A+: 90% and above
- A: 80–89.99%
- B: 70–79.99%
- C: 60–69.99%
- D: 50–59.99%
- E: below 50% if the student passes every subject
- F: fails if any subject mark is below 35

These are example grading rules for this project. Change them in `script.js` if your school uses a different system.
